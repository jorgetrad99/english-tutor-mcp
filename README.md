# English Tutor MCP

A remote MCP server that turns Claude (and later ChatGPT) into a persistent, voice-first English tutor for Spanish-speaking professionals: the server keeps the diagnostic level, adaptive plan, session history, spaced-repetition glossary and per-session metrics, while the user's own chat client runs the lesson. The full product and technical requirements live in [docs/requirements.md](docs/requirements.md); the development harness is described in [docs/harness.md](docs/harness.md).
